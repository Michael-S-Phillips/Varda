# Band Depth (example plugin)

Adds **Processing → Spectral Parameters → Band Depth**: the depth of an
absorption at a chosen wavelength, relative to a straight continuum between
two shoulders. Install it with **Plugins → Install from Folder…** and choose
this folder.

It's the example the [plugin authoring guide](../../authoring.md) walks
through. Run its test with `uv run pytest docs/plugins/examples/band-depth`.
